# Known Limitations

- Payment integration is **not verified end-to-end**. Billing is a foundation/customization area until checkout, webhooks, cancellation and renewal are tested.
- Production moderation requires live role and workflow verification.
- Email notifications are not verified as a production service.
- Booking logic must not be marketed as complete unless its full journey is tested.
- Analytics are implementation-dependent and require live event verification.
- Automated subscription renewals are not verified.
- The project has no demonstrated real marketplace traction, revenue, or active-user base.
- Data import/migration tools are not verified.
- A mobile app is not included in this web repository.
- Demo data must never be represented as real customers, verified reviews, or real commercial activity.
